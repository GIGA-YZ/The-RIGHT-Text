# The-RIGHT-Text
✨🔁 The RIGHT text – RTL alignment for Claude, ChatGPT, Gemini &amp; DeepSeek. 🌙 Dark mode + neon toggle. 🚫 No data collected.


---

## 📥 How to install ?

- Click the green **“Code”** button → **“Download ZIP”** 
- **Extract the ZIP file**
- **Open Chrome (or Brave, Edge, Vivaldi, Opera)** and type `chrome://extensions` in the address bar
- **Enable “Developer mode”** (toggle in top‑right corner)
- **Click “Load unpacked”** → select the extracted folder (the one containing `manifest.json`)
- **Pin the extension** by clicking the puzzle piece icon 🧩 in the toolbar and finding “The RIGHT text”

> ✅ The extension works on Claude, ChatGPT, Gemini, and **DeepSeek**.  
> 🔁 Toggle RTL on/off via the popup – your preference is saved per site.  

---

That’s it !. Users get the neon dark mode, RTL alignment, and full privacy.
